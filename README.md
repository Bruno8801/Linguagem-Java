# Linguagem Java - Programação Orientada a Objetos (POO)

Este repositório reúne projetos e exemplos práticos desenvolvidos durante a disciplina de
**Programação Orientada a Objetos (POO)**, complementados por estudos e pesquisas independentes.  
O objetivo é demonstrar domínio dos conceitos fundamentais e intermediários de **Java**, servindo
como portfólio técnico e aprendizado contínuo sobre o tema.

## 📚 Conteúdo

Os exemplos estão organizados em tópicos que refletem os principais pilares da POO:

1. **Classes e Objetos - conceitos iniciais**  
   Criação de classes, instâncias e atributos.

2. **Encapsulamento e Visibilidade**  
   Uso de modificadores de acesso e boas práticas de encapsulamento.

3. **Coleções e Estruturas de Dados**  
   Implementações com `HashMap` e outras estruturas.

4. **Herança**  
   Reutilização de código e hierarquia entre classes.

5. **Polimorfismo**  
   Sobrescrita e sobrecarga de métodos, comportamento dinâmico.

6. **Tratamento de Exceções**  
   Estrutura de controle de erros (`try`, `catch`, `finally`) e exceções personalizadas.

7. **Exemplos Avançados**  
   Projetos de nível intermediário que exploram padrões de projeto, boas práticas e desafios além da sala de aula.

## 🚀 Objetivo

Este repositório foi construído para:
- Consolidar o aprendizado em POO.  
- Demonstrar capacidade de aplicar conceitos em problemas reais.  
- Servir como evidência prática de conhecimento técnico para oportunidades profissionais.

## 🛠️ Tecnologias

- **Java**  
- IDEs recomendadas: IntelliJ IDEA, Eclipse ou VS Code  
- GitHub para versionamento e apresentação
